# Voxelcraft
This is Minecraft, but reamde with custom textures, redesigned UI, stripped of bloatware and isn't owned by Microslop. The game engine and shaders are running from WebGL, and updates are according to your ideas (let me know in my Discord or in here, in the Issues tab), and I also add updates, so enjoy custom Minecraft, called Voxelcraft. 





About Voxelcraft

Welcome to Voxelcraft, an independent project designed to capture the classic block-building experience while bringing a fresh and modern perspective to the genre. The repository is set up under the owner handle FitOfficial70 and serves as the central hub for the game's source code and development. This project is built by passion and creativity, aiming to provide a fun playground for everyone interested in block-based games.

The core vision behind Voxelcraft is to reimagine the traditional gameplay style with custom textures, a completely redesigned user interface, and the removal of unnecessary bloatware. By stripping away extra baggage, the game focuses purely on performance, smooth mechanics, and a clean aesthetic. Every texture and menu has been thoughtfully updated to give the project its own unique identity while keeping the gameplay familiar and engaging.

As a public repository, Voxelcraft invites players, developers, and enthusiasts to look into its progress and development stages. Being open to the public allows transparency and lets the community see how the project evolves over time. Whether you are here to check out the code structure or follow the updates, the repository provides a clear window into the creation process.

The development setup is streamlined to keep things simple and efficient. With the README option turned on, visitors are greeted with clear introductory information right when they land on the page. Meanwhile, other configurations like the .gitignore file are kept minimal, ensuring that the project workspace stays organized as new features and custom assets are added.

Ultimately, Voxelcraft represents a creative outlet for building a personalized spin on a beloved gaming concept. It stands as an independent endeavor focused on delivering a lightweight, customized experience without corporate backing or complex commercial layers. It's all about keeping things fun, lightweight, and true to the creator's vision.
