Voxelcraft World

Your worlds are saved in this browser on this device. Export a backup to keep a separate copy.

Marketplace add-ons can be marked as loaded for this world without downloading a file. This is a simulated load state; imported Minecraft files and catalog entries do not execute or change gameplay in this browser build.

Creating a world adds it to your saved worlds. Existing worlds will not be replaced.

Multiplayer is not available yet. Your singleplayer world is ready to play.

MARKETPLACE

Create your own catalog entries or import a Minecraft file for safekeeping. Custom entries are saved in this browser; use COPY CODE to copy a snippet you can paste into the page script to keep that entry in the source too.

Imported files are stored in this browser and can be downloaded, but this game cannot install or run Minecraft mods. Accepted files: Java mod .jar and Bedrock .mcpack, .mcaddon, .mcworld, or .zip.

SETTINGS

Choose how much terrain loads around you. Larger distances use more memory. This browser build supports up to 4 chunks in each direction. Larger distances load more terrain and use more memory. Thus, it can cause bugs.
